- **Registry signatures carry their actual scheme.** Ed25519ph signatures are now labeled with their own algorithm identifier instead of `id-Ed25519`, which now marks only pure Ed25519 signatures (made by keys held in gpg-agent). Existing signatures are relabeled on upgrade. StartOS 0.4.0.3 and earlier still receive the old labels, without the pure signatures they cannot verify. Reading from or publishing to this registry requires start-cli 2.5.0 or later.
- **A registry serving StartWRT must set `startwrt: true`** in its config (or pass `--startwrt`), so routers keep receiving the labels they understand.
