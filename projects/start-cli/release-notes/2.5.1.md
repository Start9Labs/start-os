**start-cli 2.5.1 handles closed output pipes without crashing and can generate WireGuard configs with an independently chosen endpoint.**

## Highlights

- Piping output into a command that stops reading early, such as `head`, no longer crashes the CLI.
- `tunnel device show-config --endpoint` supplies an IPv4 address, IPv6 address, or DNS name without changing the WAN assignment used for forwarding and SNAT. Requires StartTunnel 1.4.1 or later.
