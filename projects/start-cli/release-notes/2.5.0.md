**start-cli 2.5.0 manages private packages on start-registry 1.2.0, chooses which registries a StartOS server signs its requests to, preserves start requests while critical tasks block execution, and completes commands in Bash automatically.**

## Highlights

- **`registry package access` makes a package private and manages who can see it**: `set-private`, `add-reader`, `remove-reader`, and `get`.
- **`server registry-signing add <URL>` has a StartOS server sign its requests to that registry**, so the registry can show it private packages. `server registry-signing key` prints the key for the registry admin to add as a signer.
- **`package start` records running intent while critical tasks block execution and prints a warning.** The service starts automatically once those tasks clear.
- **Complete `start-cli` commands and options with Tab in new Bash shells**, without editing a shell profile.

## Important

`package start --force` is removed. Remove `--force` from scripts.
