**A patch release: package code written for 3.0.4 type-checks again.**

- **Action results, images and device filters type-check as written for 3.0.4.** Action results may omit `launchable`, Dockerfile images may omit `workdir`, device filters and notifications may omit their optional fields, and `getContainerIp` for the service's own container returns a string.
