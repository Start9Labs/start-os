**0.4.0.4 fixes menus and dropdowns that would not open when reduced motion is on, and tightens sign-in handling.**

## Highlights

- **Menus and dropdowns open with reduced motion on.** The Start Menu, the Marketplace registry picker, and every other dropdown in the web UI show again when the browser or OS has reduced motion turned on.
- **Revoking a sign-in closes its idle streams immediately.**
- **`start-cli auth login` and `auth logout` on the server itself** explain that no login is needed there, instead of failing with an unclear error.
